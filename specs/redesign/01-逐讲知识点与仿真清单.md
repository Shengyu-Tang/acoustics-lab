## 第 1 章 集中参数振动（10 讲）

**1.1.1 单自由度无阻尼自由振动（1）**
- PPT：弹簧振子模型（M、D、C_M）、胡克定律、振动方程 Mẍ + Dx = 0、通解、初始条件确定特解；固有频率只由 M、D 决定。
- 图 1.1.1-1：x(t) = x₀cos ω₀t（虚线）+ (v₀/ω₀)sin ω₀t（点线）与合成曲线（实线），左侧配弹簧振子示意动画。
- 参数：M、D、x₀、v₀；读数：f₀、T、振幅 A、初相 φ。
- 校验：改变 x₀ 正负（拉伸/压缩）或 v₀，f₀ 不变（对应思考题 2）。

**1.1.2 单自由度无阻尼自由振动（2）**
- PPT：位移、速度、加速度的幅度与相位关系；复数表示与复平面旋转矢量；动能、势能互换，总能量守恒。
- 图 1.1.2-1：`subplot(3,1,k)` 依次画 x、v、a，竖直虚线标出相位超前 π/2。
- 图 1.1.2-2：复平面上 x̃、ṽ、ã 三个旋转矢量（同步动画），实轴投影即实际值。
- 图 1.1.2-3：E_k(t)、E_p(t)、E(t) 三条曲线，E 为水平线。
- 校验：|v|max = ω₀A，|a|max = ω₀²A；E_k + E_p 恒等于 ½DA²。

**1.1.3 单自由度有阻尼自由振动（1）**
- PPT：牛顿（粘滞）阻尼、运动方程、特征根；大阻尼（δ > ω₀）时不振动，三种初始条件下的曲线。
- 图 1.1.3-1：大阻尼时三种初始条件 (x₀,0)、(0,v₀)、(x₀,v₀) 的 x(t) 三条曲线（同一坐标）。
- 图 1.1.3-2：s 平面上两个特征根位置随 δ 变化（δ 从 0 增到 2ω₀ 时根的轨迹，标出临界阻尼点）。
- 校验：δ > ω₀ 时两根为负实数且 x(t) 过零不超过一次。

**1.1.4 单自由度有阻尼自由振动（2）**
- PPT：小阻尼时振幅按 A₀e^{-δt} 衰减的“准简谐”振动，过零间隔相等；固有频率 ω₀' = √(ω₀² − δ²)；平均能量按 e^{-2δt} 衰减。
- 图 1.1.4-1：x(t) 与 ±A₀e^{-δt} 包络（虚线），标出相邻过零点间隔。
- 图 1.1.4-2：`semilogy` 画平均能量 Ē(t)，呈直线，斜率 −2δ。
- 读数：ω₀'、ω₀、两者相对差。
- 校验：数值积分（RK4）结果与解析解误差 < 0.1%。

**1.1.5 阻尼振动系统中阻尼量的描述**
- PPT：阻力系数 R_m、阻尼系数 δ、品质因数 Q_m 三种描述；Q_m 为振幅衰减到 e^{-π} 所经过的周期数；Q_m 反比于每周期能量损失相对值。
- 图 1.1.5-1：Q_m = 1.7、5、10 三个系统的自由衰减曲线（同一坐标，三色），每条标出“振幅降到 e^{-π}”的位置与对应周期数。
- 换算器：输入任意一个（R_m 或 δ 或 Q_m）+ M、D，自动给出另外两个及对数衰减率。
- 校验：数出的周期数等于 Q_m（取整误差内）。

**1.2.1 单自由度无阻尼强迫振动**
- PPT：解 = 自由振动分量 + 强迫振动分量；零初始条件下的拍；ω → ω₀ 时振幅线性增长。
- 图 1.2.1-1：零初始条件下 x(t)，叠加拍包络；`subplot` 上方画外力 f(t)。
- 图 1.2.1-2：ω = ω₀ 时 x(t) 振幅线性增长（包络为直线）。
- 参数：ω/ω₀（0.5–1.5）；读数：拍周期 2π/|ω − ω₀|。
- 校验：拍周期读数与曲线包络周期一致。

**1.2.2 单自由度有阻尼强迫振动**
- PPT：通解（暂态）+ 特解（稳态）；暂态以固有频率振动并衰减，稳态以外力频率振动。
- 图 1.2.2-1：`subplot(3,1,k)`：暂态分量、稳态分量、合成位移，时间轴对齐。
- 校验：t ≫ 1/δ 时合成位移与稳态分量重合。

**1.2.3 强迫振动的过渡过程**
- PPT：零初始条件、ω = ω₀ 时振幅按 1 − e^{-δt} 建立；过渡时间（达到稳态 95%）；ω ≈ ω₀ 时过渡期出现逐渐消失的拍；正弦脉冲填充激励在 Q_m = 1.7、5、10 下的波形畸变。
- 图 1.2.3-1：ω = ω₀ 时 x(t) 与 1 − e^{-δt} 包络，`xline` 标出过渡时间。
- 图 1.2.3-2：ω 略偏离 ω₀ 时的衰减拍。
- 图 1.2.3-3：`subplot(3,1,k)` 复现 PPT 三张图：正弦填充矩形脉冲激励下 Q_m = 1.7、5、10 的响应，叠画激励包络。
- 读数：过渡时间 τ₀ = ln20/δ ≈ 3/δ；与 Q_m 的关系。
- 校验：τ₀ 读数与 95% 包络时刻一致。

**1.2.4 强迫振动的稳态振动（1）**
- PPT：机械阻抗 Z_m = R_m + j(ωM − D/ω)；位移、振速、加速度的幅频与相频特性；三种响应的共振频率不同。
- 图 1.2.4-1：`subplot(2,3,k)`：上排 x_m、v_m、a_m 幅频曲线，下排对应相频曲线；三张幅频图分别用 `xline` 标出位移共振 f₀√(1−2ζ²)、速度共振 f₀、加速度共振 f₀/√(1−2ζ²)。
- 图 1.2.4-2：|Z_m|、R_m、X_m 随频率曲线（X_m 过零处即 f₀）。
- 参数：M、D、R_m（或 Q_m）、F₀；可切换 Q_m = 1.7/5/10 叠画对比。
- 校验：三种共振频率读数与公式一致；Q_m 越大峰越尖。
- 参考教师自制课件《第4次课_频率特性与功率带宽及弦的建模》中的频率特性图。

**1.2.5 强迫振动的稳态振动（2）**
- PPT：瞬时功率、平均（机械）功率、输入功率等于阻尼消耗功率；谐振频率；半功率点带宽 Δf = f₀/Q_m。
- 图 1.2.5-1：瞬时功率 p(t) = F(t)v(t) 曲线与其平均值水平线（分别取 f < f₀、f = f₀、f > f₀ 三种，`subplot`）。
- 图 1.2.5-2：平均功率 W̄(f)，标出峰值与两个半功率点 f₁、f₂，阴影标出 Δf。
- 校验：数值求得的 f₂ − f₁ 与 f₀/Q_m 误差 < 0.5%。

## 第 2 章 弦与棒的振动（4 讲）

**2.1 弦的振动**
- PPT：两端固定张紧柔软弦的微元受力分析（张力 T₁、T₂，夹角 θ₁、θ₂），小振幅近似得横振动方程 ∂²y/∂t² = c²∂²y/∂x²，c = √(T/ρ_l)；分离变量形式解；四种边界条件（固定、外力激励、位移激励、振速激励）。
- 图 2.1-1：可交互的微元受力图（拖动弦形，显示两端张力分量与合力）。
- 图 2.1-2：四种边界条件切换示意 + 对应边界方程。
- 读数：c = √(T/ρ_l)（输入张力与线密度，可选吉他/古筝弦参数）。

**2.2 弦振动方程的解**
- PPT：两端固定弦自由振动：f_n = nc/2L，基频、泛频、谐频，简正振动与振型；一端固定一端谐和力激励的稳态解与共振频率。
- 图 2.2-1：前 6 阶振型（`subplot(3,2,k)`），标出波节。
- 图 2.2-2：拨弦初始形状（拨点位置可调）→ 各阶系数 b_n 的柱状图（`bar`）→ 合成运动动画。
- 图 2.2-3：一端固定、一端力激励时弦端位移幅值随频率曲线，标出共振频率 f_n = (2n−1)c/4L。
- 校验：拨点在 L/2 时偶数阶系数为 0；共振频率与公式一致。

**2.3 均匀细棒的纵振动**
- PPT：细棒近似（截面线度 ≪ 波长）、纵振动方程，c = √(E/ρ)；形式解；四种边界条件（固定、自由、质量负载、激励力）。
- 图 2.3-1：体元受力图（应力 T_z 在两截面的差）。
- 图 2.3-2：常见材料（钢、铝、黄铜、玻璃、有机玻璃）纵波声速柱状图。
- 图 2.3-3：质量负载边界的频率方程图解：画 tan(kL) 与 ρSL/(M·kL) 两条曲线，交点即各阶固有频率（M 可调）。

**2.4 均匀细棒纵振动方程的解**
- PPT：两端自由细棒 f_n = nc/2L 与振型；一端固定一端谐和力激励的稳态解与共振 f_n = (2n−1)c/4L；共振法测杨氏模量。
- 图 2.4-1：两端自由前三阶位移振型（cos 分布）。
- 图 2.4-2：一端固定、一端力激励的端点位移幅值随频率曲线。
- 计算器：输入测得基频、棒长、密度 → 求 c 与 E（分步显示）。
- 校验：钢棒 L = 1 m 两端自由基频约 2.5 kHz。

## 第 3 章 声波的传播（50 讲）

### 3.1 基本概念与三个基本方程

**3.1.1 什么是声？** 声的两种含义；声波是机械波；两个必要条件（声源、介质）；质点只在平衡位置附近振动；纵波与横波。
- 图 3.1.1-1：一排质点的纵波/横波切换动画，单独高亮一个质点并在下方画它的位移-时间曲线，说明质点不随波迁移。

**3.1.2 三个基本声学量** 声压、质点振速、密度逾量（压缩量）；1 Pa 在空气与水中对应的振速与位移量级；振速 ≠ 声速。
- 图 3.1.2-1：输入声压级与频率，选空气/水，给出 p、u、ξ、ρ'、s 的数值表；`loglog` 柱状对比空气与水中的 u 与 ξ。
- 校验：空气 1 Pa、1 kHz：u ≈ 2.4×10⁻³ m/s，ξ ≈ 3.8×10⁻⁷ m；水中 u ≈ 6.7×10⁻⁷ m/s，ξ ≈ 1×10⁻¹⁰ m（与 PPT 量级一致）。

**3.1.3 波动方程推导的假设条件** 理想、连续、可压缩、均匀静止、小振幅五个假设；三个基本物理定律。
- 图 3.1.3-1：五个假设的勾选面板，每取消一个就显示一张对比小图：去掉“小振幅”→ 大振幅波形逐渐变陡（非线性畸变）；去掉“理想”→ 振幅衰减；去掉“均匀”→ 声线弯曲。
- 图 3.1.3-2：推导路线图（三个定律 → 三个方程 → 波动方程），点击跳到对应讲。

**3.1.4 连续性方程（1）** 质量守恒；六面体体元；x、y、z 方向流入流出质量。
- 图 3.1.4-1：三维六面体 ABCDEFGH（浅色 `quiver3` 风格），ABCD 面与 EFGH 面上的质量流箭头长度按 ρu 在两面的值变化，体内颜色表示密度变化。
- 图 3.1.4-2：x 方向净流入质量 = −∂(ρu)/∂x·dxdydzdt 的逐项数值演示（输入两面流速，算出体内密度变化率）。

**3.1.5 连续性方程（2）** 散度形式 ∂ρ/∂t = −∇·(ρU)；小振幅线性化 ∂ρ'/∂t = −ρ₀∇·u。
- 图 3.1.5-1：同一时刻 ∂ρ'/∂t 与 −ρ₀∂u/∂x 两条曲线重合（`plot` 叠画）。
- 图 3.1.5-2：被略去的二阶小量 ∇·(ρ'u) 与保留项的比值随声压幅值变化（`loglog`），说明小振幅近似的适用范围。

**3.1.6 状态方程** 等熵过程、P(ρ, s₀) 幂级数展开、略去高阶小量得 p = c₀²ρ'。
- 图 3.1.6-1：空气绝热曲线 P = P₀(ρ/ρ₀)^γ 与在 (ρ₀, P₀) 处的切线（斜率 c₀²），可放大观察小振幅区；读出线性化误差随 ρ'/ρ₀ 的变化。

**3.1.7 介质的波速** 等熵波速（拉普拉斯）与等温波速（牛顿）；c₀ 随静压与温度变化；音频为绝热、次声为等温。
- 图 3.1.7-1：两种波速随温度变化曲线，标出 0 °C 时 331 m/s 与 280 m/s。
- 读数：输入 T、γ、P₀，给出两种波速与相对差。

**3.1.8 运动方程** 质团受力（压强梯度）；加速度 = 本地加速度 + 迁移加速度；小振幅近似得 ρ₀∂u/∂t = −∇p。
- 图 3.1.8-1：p(x) 与 −∂p/∂x、ρ₀∂u/∂t 三条曲线（后两条重合）。
- 图 3.1.8-2：迁移加速度与本地加速度之比 ≈ u/c₀（马赫数）随声压级变化（`semilogy`）。

**3.2.1 波动方程的推导（1）** 三方程消元得声压波动方程；拉普拉斯算子在直角、球、柱坐标下的形式。

**3.2.2 波动方程的推导（2）** 速度势函数 u = −∇φ，p = ρ₀∂φ/∂t；速度势、密度逾量、压缩量的波动方程。

### 3.3 声场中的能量关系

**3.3.1 声能量密度** 声动能与声势能；E₀ = ½ρ₀u² + p²/(2ρ₀c₀²)。
- 图 3.3.1-1：行波中某时刻 E_k(x)、E_p(x)、E₀(x)（E_k 与 E_p 重合）；切换到驻波时两者此消彼长。

**3.3.2 声能流密度** 定义、单位；能量守恒 ∂E₀/∂t = −∇·W（与质量守恒对照）。
- 图 3.3.2-1：六面体控制体能量流入流出动画，与 3.1.4 图并列对照（质量守恒 ↔ 能量守恒）。

**3.3.3 声能流密度和声强** W = pu（取实部相乘）；正负号的物理意义；声强 = 时间平均；驻波中声强为 0；声强级。
- 图 3.3.3-1：p(t)、u(t) 与瞬时能流 W(t) 三条曲线，p 与 u 相位差 φ 可调（0–π/2），水平线显示平均值 I = ½p_a u_a cos φ。
- 校验：φ = π/2 时 I = 0；W(t) 有正有负时说明能量来回交换。

### 3.4 平面波

**3.4.1 谐和平面波场（1）** 平面波定义；一维亥姆霍兹方程；形式解 Ae^{j(ωt−kx)} + Be^{j(ωt+kx)}；无限远条件下的行波。
- 图 3.4.1-1：正向波、反向波及其合成（A、B 可调），B = 0 时为行波。

**3.4.2 谐和平面波场（2）** 周期、频率、角频率；波长、波数；相位落后 kx；波形不变地平移，速度 c₀；介质压缩性影响声速。
- 图 3.4.2-1：左图固定 x 画 p(t)（标出 T），右图固定 t 画 p(x)（标出 λ），两图联动；拖动观察点显示相位落后 kx₁。

**3.4.3 谐和平面波场（3）** 等相位面与相速度；质点振速与声压同相，比值为 ρ₀c₀。
- 图 3.4.3-1：复现 PPT：t₁ < t₂ < t₃ 三个时刻 p 与 u 的空间分布（`subplot(3,1,k)`）。
- 图 3.4.3-2：x₁ < x₂ < x₃ 三个位置的时间波形。

**3.4.4 谐和平面波场（4）** 波阻抗 Z_a = p/u；平面行波 Z_a = ρ₀c₀；与特性阻抗的区别；行波能流与声强处处相等。

**3.4.5 一般平面波** 达朗贝尔解 f₁(x − c₀t) + f₂(x + c₀t)；任意波形不变地传播；u = p/ρ₀c₀。
- 图 3.4.5-1：可选脉冲 / 三角波 / 学生手绘波形，向右平移动画；可加入反向波观察叠加。

**3.4.6 声压级和声强级** “级”与分贝；SPL、SIL、SWL；空气与水中参考值；SIL 与 SPL 的修正项 10lg(400/ρ₀c₀)。
