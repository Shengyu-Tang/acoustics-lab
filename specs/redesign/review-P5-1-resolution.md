# P5 第 1 轮评审处理记录

评审来源：[review-P5-1.md](review-P5-1.md)。本轮只处理评审要求，不启动 P6 功能开发。

1. **案例目录**：移除 CSS 多栏，使用占满可用宽度的单列编号列表，长标题可换行。`check-browser` 比较全部 9 项的包围盒和文本包围盒；包围盒包含外置编号及 4 px 横向间距。旧目录样式回放触发断言，修复后通过 320、390、640、768、769、1024、1440 px 的检查。
2. **分步解答**：先在 `npm test` 已有的排版检查中增加实际参考解答 HTML 检测。修复前检测到 1.2.3、3.5.1、精密车间、琴弦和通风管道中的 `exp` / `hypot` 写法。已分别改为 KaTeX 指数、平方和开方及分式；原始计算函数与 MATLAB 导出表达式保留。测试覆盖全部 79 讲、9 案例的实际默认解答，以及默认值、另一组参数和每个参数端点共 806 组解答文本。
3. **水浸术语**：案例背景明确为水浸检测线、水—钢界面和水槽校准，案例标题与目录原本已经统一使用“水浸超声探头”。新增 `check-terminology.mjs` 检查 300 个站点源码和资源文件，防止误写回归；评审原文中的引述保留。
4. **全站复核**：`check-browser` 增加全部 79 讲和 9 案例在桌面 1440×900、手机 390×844 下的展开解答、真实输入修改与重算、公式解析、编程记号及页面横向溢出检查。保留原有路由和交互验证，并补充三种对照实验的 URL。目录以及 1.2.3、1.2.4、3.5.1、3.7.1、通风管道、精密车间、琴弦、水浸探头的解答截图保存于 `outputs/browser-screenshots/p5-review/`。

回归失败及通过日志保存在本克隆的 `outputs/p5-review-*.log`；浏览器覆盖明细保存在 `outputs/p5-review-report.json`。

最终验证全部通过：`npm ci` → `npm test` → `node scripts/check-animations.mjs` → `npm run build` → `node scripts/check-browser.mjs`，以及 `git diff --check`。浏览器检查覆盖 202 组不同路由与视口组合、178 次展开解答检查（含目录默认案例），控制台错误为 0。已人工查看目录及上述 8 份解答的桌面、手机截图，共 18 张。可提交的覆盖明细见 [P5-review-validation.json](P5-review-validation.json)。
