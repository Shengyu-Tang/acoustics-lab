## 2. 改版目标

1. 网站看起来像一门**成熟课程的教学网站**（参考气质：MathWorks 帮助中心、MIT OpenCourseWare 课程页、教材配套网站），信息密度高、排版克制、以内容为主。
2. **慕课 79 讲每一讲都有与 PPT 内容一一对应的直观展示或仿真**，逐讲要求见 `01-逐讲知识点与仿真清单.md`。
3. 所有曲线图统一为 **MATLAB 风格**，并可导出 PNG、CSV 和可直接运行的 `.m` 脚本。
4. 每讲至少一道**可计算的例题**，带分步参考解答；9 个综合工程案例改成多步设计计算题。规范见 `02-工程计算案例规范.md`。
5. 保持纯静态 GitHub Pages、无登录、无后端。

## 3. 视觉与交互规范（“去 AI 模板化”）

### 3.1 明令禁止的样式

- 页面顶部“超大标题 + 一行灰色小字副标题”的 hero 区；任何营销式口号（如“让声音的规律，看得见。”）。
- 标题上方的英文全大写眉标（CHAPTER 01、PHYSICS、ENGINEERING STUDIO、THINK FIRST 等）。
- 统计数字块（“7 个课程章节”“82 个知识点”作为装饰）。
- 卡片网格 + 阴影 + 大圆角（radius > 4px）；渐变色；毛玻璃；深色仪表盘面板。
- 每个链接后面的 ↗ 箭头；胶囊标签（pill）堆叠；emoji 图标。
- 同一页面超过 1 个强调色。

### 3.2 版式

- **全站结构**：顶部导航条（高 56px，左侧“声学基础 · 中国海洋大学”，右侧：课程章节、综合案例、教学日历、教师主页、反馈）。
- **知识点页三栏**：左侧章节目录树（按教材编号 1.1.1、3.6.10，可折叠，当前讲高亮）；中间正文阅读栏（最大宽 860px，图可扩展到 1100px）；宽屏右侧“本页目录”。手机端左栏收进抽屉，右栏隐藏。
- **知识点页正文顺序**（像一页讲义）：
  1. 标题：`3.10.5 声波在平行平面层波导中的传播（5）`，下方一行“对应慕课：3.10.5 …PPT.pdf · 第 X 次课”。
  2. **本讲要点**：3–5 条，取自 PPT 的“总结”页。
  3. **原理**：核心公式，按 `(3.10-7)` 形式编号，公式下一句话说明物理意义。
  4. **仿真**：按 `图 3.10.5-1 …` 编号的 MATLAB 风格图；图下方是参数面板（像 MATLAB uicontrol：标签、数值框、单位、滑块紧凑排成一行或两列），以及关键读数表。
  5. **例题与参考解答**（见 02 文件）。
  6. **思考题**：慕课原题，答案默认折叠。
  7. **工程应用**：一段工程情境 + 链接到对应综合案例。
  8. 上一讲 / 下一讲。
- **首页**不是落地页，而是课程主页：一段课程简介（3–4 行）→ 章节目录表（章、讲次、每讲一个代表图缩略图）→ 本周课程（取自教学日历）→ 教师信息一小块。

### 3.3 字体与颜色

- 中文正文：`"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`，16px，行高 1.75；标题用宋体系 `"Noto Serif SC","Songti SC",serif`。公式用 KaTeX。
- 颜色：正文 `#1a1a1a`，次要文字 `#555`，分隔线 `#d9d9d9`，背景纯白 `#fff`，唯一强调色海大蓝 `#1F5FA8`（链接、当前项、按钮）。不使用其他装饰色；图内配色遵循第 4 节。
- 用细分隔线和留白组织内容，而不是卡片。按钮为 1px 边框、4px 圆角。

## 4. MATLAB 风格绘图规范（新建统一组件）

新建 `src/plot/` 下的统一 SVG 绘图组件（例如 `<Figure>`、`<Axes>`、`<Line>`、`<Polar>`、`<Image>`），**全站所有曲线图必须通过它绘制**，不允许各页面自己手写 SVG 曲线。

| 项目 | 要求（对齐 MATLAB R2014b 以后默认外观） |
|------|------|
| 背景 | 图窗白色，坐标区白色，`box on` 四边黑色细框 |
| 网格 | `grid on`，浅灰（约 `#e5e5e5`），刻度线朝内 |
| 字体 | Arial/Helvetica 系，刻度 11px，轴标签 12px，标题 12px 加粗；中文标签回退到正文中文字体 |
| 线色顺序 | `#0072BD #D95319 #EDB120 #7E2F8E #77AC30 #4DBEEE #A2142F` |
| 线型 | 数据线宽 1.5，可选 `'-' '--' ':' '-.'` 与标记 `o s ^ x` |
| 轴 | 支持 `plot / semilogx / semilogy / loglog / polarplot / imagesc(带 colorbar) / subplot(m,n,k) / yyaxis` |
| 色图 | 场分布用 `parula`（64 级），对称场可用 `RdBu` 发散色图；禁止 `jet` |
| 标签 | `xlabel('频率 f (Hz)')` 形式，单位一律在括号内；`legend` 白底带框，默认右上 |
| 数据提示 | 鼠标悬停显示 MATLAB 式数据提示框 `X: 31.6  Y: 3.14` |
| 工具条 | 每张图右上角三个按钮：导出 PNG、导出数据 CSV、**导出 MATLAB 代码**（生成可直接在 MATLAB 运行、能复现当前参数下该图的 `.m` 脚本） |
| 动画 | 允许时间动画，但坐标轴固定不跳动（类似 `drawnow`），提供播放/暂停/单步 |
| 标注 | 关键点（共振频率、截止频率、半功率点、临界角等）用 `xline/yline` 虚线 + 文字标注 |

三维几何示意（如六面体控制体、活塞换能器）可以保留 three.js，但配色改为浅色背景、灰色几何体、蓝色/橙色箭头，与 MATLAB `surf/quiver3` 观感一致。

## 5. 内容数据结构

- 每讲一个数据文件 `src/content/lectures/<编号>.ts`（或 JSON），字段至少包括：`id`、`title`、`moocSource`、`keyPoints[]`、`formulas[]`（含编号与说明）、`figures[]`（每张图：编号、标题、绘图函数、参数定义、读数）、`examples[]`（见 02 文件）、`questions[]`（慕课思考题与参考答案）、`engineering`。
- 物理计算放在纯函数模块（`src/physics/<章>.ts`），绘图组件只负责画；每个函数有单元校验（沿用 `scripts/check-*.mjs` 的风格）。
- 删除不再使用的 `backend/`、`Account.tsx`、`Admin.tsx`、`Comments.tsx`、`Queue.tsx`、`api.ts`、`check-auth.mjs`（历史记录保留在 git 历史中即可）。
- 引入 Prettier，源码按常规多行格式书写。
