# 审查意见：参数必须在图上看得见（教师反馈）

教师审查 2.1 弦的横振动时发现：改变弦长 L，仿真图上弦的长度不变。原因是横轴用归一化坐标 x/L（0–1），L 只进了读数，没有进图。这类“改了参数图不动”的错误不允许再出现。

## 规则（P1–P6 全部讲次适用）
1. **几何参数用物理坐标画**：长度、半径、距离、厚度、孔径等几何量，横轴/纵轴用带单位的物理坐标（如 x (m)），坐标范围取该参数滑块的最大值并固定，使改变参数时图形的长短、大小肉眼可见。需要归一化视图时可另加一个面板，但主图必须是物理坐标。
2. **每个参数都要影响图**：参数面板里的每个参数，改动后至少有一张图的曲线、形状、位置或标注发生可见变化；只影响读数的参数要么移到例题已知条件里，要么在图上加对应标注（例如标线、数值标签）。
3. **坐标轴固定**：调参数时坐标范围不随数据自动缩放（动画同理，按 00 文件第 4 节），否则变化被缩放抵消、看不出来。纵轴范围按参数取值范围内的最大响应确定。

## 必须新增的自动检查（加入 npm test）
- 参数灵敏度测试：对每一讲的每个参数，分别取默认值和滑块范围内另一值（如 min 与 max），生成该讲全部图的数据；断言至少一张图的数据点发生变化（相对变化 > 1%），否则测试失败并列出“讲次—参数”。确有理由只影响读数的参数需在讲义定义里显式标注 `affects: "readout"` 并写明理由，测试列出这些参数供审查。
- 几何参数测试：被标记为几何量（单位为 m 的长度类参数）的参数，改变后图中对应几何的范围（如弦的端点横坐标）必须随之改变。
- 坐标轴测试：同一讲改变参数前后，xlim/ylim 保持不变（动画和带“自动范围”说明的图除外，需显式标注）。

## 补充（Claude 审查）
- 不得用可调参数对坐标轴归一化（x/L、t/T、f/f₀、kr……）。用物理单位（x 用 m、t 用 s、f 用 Hz），坐标上限固定为该参数滑块最大值（如 L 为 0–1.5 m），使弦/棒/声场明显变长变短而坐标轴不跳动。只有图的目的本身是无量纲比较时才允许归一化轴，此时图注须说明，并在面板中标出哪些参数不影响该图。
- 审查范围包括固定长度的三维/场景示意图忽略 L、a、d 等参数的情况。
- 灵敏度测试使用每张图的 `independentOf` 列表（替代上文的 affects: "readout"）：图明确声明与某参数无关时，界面在图下方用灰色小字显示（如“本图与 L 无关”），测试跳过该组合；读数在其输入改变时也必须改变。该测试在当前 2.1 上必须失败（修复前先确认能抓到这个错误）。
- 自己的 Playwright 检查：每一讲把每个滑块分别拖到两端并截图，推送前逐张查看。
