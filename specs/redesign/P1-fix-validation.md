## MATLAB 和浏览器验收

`C:\Program Files\MATLAB\R2024b\bin\matlab.exe -batch` 实跑最终 88 份脚本，每份脚本独立进程，临时目录与偏好均位于本仓库。第二组只编辑第一组脚本的参数块，不重新生成计算公式；与网页物理函数逐点比较全部曲线坐标、讲次读数和例题答案。奇点以 NaN 断开，比较同时检查非有限值及样本数量。数值容差为 `abs(MATLAB−网页)/max(1,abs(网页)) < 2e-9`。

精确数值、两组参数、每图结果见 [results.json](matlab-check/P1-fix/results.json)；汇总、文件尺寸及 SHA-256 见 [P1-fix-validation.json](P1-fix-validation.json)。复现命令：

```powershell
node scripts/check-matlab-models.mjs
node scripts/check-matlab-zero-energy.mjs
node scripts/verify-p1-fix.mjs
```

批量脚本可用 `--filter=2.2-2,B-1` 补跑指定图，或 `--changed-only` 只运行生成代码有变化的图。成功的补跑会合并到最终 88 项结果表。
