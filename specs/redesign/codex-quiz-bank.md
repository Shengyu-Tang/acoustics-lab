# Codex 任务：课前检测与课后自测题库（内容起草）

教师要求：“你来提供，要注意知识点要有，也要让这门课有些深度。”本任务只起草题库内容（数据文件 + 校验脚本），网页功能在后续 Phase 2 实现。

## 来源（只读）
- 每讲慕课课件 PDF：`..\04-声学基础课件资料\中国大学慕课-振动与声基础-ppt\`（总结页、例题、推导）
- 思考题：`..\04-声学基础课件资料\中国大学慕课-振动与声基础-内容简介及思考题\`
- 督导版教学设计（前测、后测、学习目标）：`..\02-教学安排\20261018督导版教学设计\第NN次课_*.docx`
- 网站已有内容：`src/content/` 中各讲本讲要点、公式、例题（题库符号必须与网站和课件一致：D、Rₘ、δ、Qₘ、ρ₀c₀、e^{jωt} 等）

## 每讲题量与结构（79 讲）
**课前检测 3 题**（2–3 分钟，检查前置知识和本讲直觉）：
- 1 题前置知识（上一讲或数学/物理基础，如复数、微分方程、量纲）
- 1 题物理直觉/现象判断（“如果……会怎样”）
- 1 题概念辨析（易混概念）

**课后自测 5 题**，按难度递进，必须覆盖本讲要点中的每个核心概念：
1. 概念理解（选择或判断，干扰项来自典型错误）
2. 公式与物理意义（选出正确表达式/判断量纲/符号含义，或判断某一项的物理来源）
3. 定量计算（填数值，±2% 判分，工程合理数值，给单位）
4. 推导或推理（选择推导中的关键一步、判断近似条件是否成立、极限情况 ka≪1 / ka≫1、低频/高频行为）
5. **深度题**（每讲至少 1 道）：多概念综合、参数影响的定性—定量结合、工程设计取舍、反例与适用条件、与前后章节联系（如把第 1 章机械阻抗类比到第 3 章声阻抗率、第 4 章辐射阻抗）。深度题要有“为什么”，不能只是代公式。

每道题包含：`id`、`lecture`、`kind`（pre/post）、`level`（基础/理解/应用/深度）、`concept`（对应本讲要点中的哪一条，原文引用）、`type`（single/multi/judge/numeric）、题干（中文，公式用 KaTeX 记号）、选项、答案（numeric 给计算式和数值、单位、容差）、**解析**（2–5 句，讲清原因；选择题说明每个干扰项错在哪里）、`source`（课件页码或教学设计条目，便于教师核对）。

## 质量要求
- 不出“背定义”的空洞题；题干要有物理情境或数值，干扰项来自真实常见错误（Hz 与 rad/s、峰值与有效值、声压级与声强级、近场与远场、刚性与软边界、相位符号约定）。
- 本讲要点中每个核心概念至少被 1 道课后自测题覆盖；生成覆盖表。
- 数值题答案用独立脚本计算并校验（`scripts/check-quiz-bank.mjs`：答案与计算式一致、容差合理、单位存在、无重复题干、每讲题数、每条要点有覆盖、每讲至少 1 道深度题）。
- 与课件符号、e^{jωt} 约定一致；不得出现与网站例题完全相同的题。
- 不出现“慕课”字样。

## 输出
- `src/content/quiz/<讲次>.json`（79 个文件）或按章合并，结构统一；
- `scripts/check-quiz-bank.mjs` 加入 `npm test`；
- `specs/redesign/quiz-bank-review.md`：每讲一张覆盖表（要点 → 题号）、深度题清单、题目来源，供教师审定；
- 一章一个提交。

## 验收
`npm ci && npm test && node scripts/check-animations.mjs && npm run build` 通过；check-quiz-bank 全部通过。

## 补充要求（Claude 审查）
1. 题干和选项里的公式一律用 $…$ KaTeX，符号与本讲页面一致（M、Rₘ、D、δ、ω₀、ρ₀、c₀、Z、k、ka 等），不出现程序写法。
2. 数值题给齐所需数据和单位，计算器 3 分钟内可完成；答案用合适的单位前缀（kHz、mm、dB），±2% 判分；check-quiz-bank.mjs 必须用独立公式复算，不调用网站 physics 代码。
3. 深度题不要写成“代公式”：每题要求学生做出一个判断或解释（极限情形、假设失效时会怎样、两种模型取舍、数量级估算、与前后章节的类比），并在解析里写出判断依据。
4. 选择题 4 个选项，干扰项各对应一个真实错误；不允许“以上都对/都不对”；正确选项位置要分散。
5. 语言朴素，像老师出的卷子；不出现“慕课”，不出现“让我们”“值得注意的是”这类套话。
6. 题库不进入网站界面，本轮只做内容。按章完成：每完成一章单独提交，由外部流程逐章推送并交审查。
7. `specs/redesign/quiz-bank-review.md`：每讲一节，列题目、答案、解析、覆盖表，便于审查者和教师阅读。

## 与雨课堂题库的分工（Claude 补充）
教师的雨课堂另有一套课堂前测/后测（第 7—24 次课，共 123 题），网站题库要与之记号一致、题目不重复。
1. 记号约定：时间因子 e^{jωt}；速度势 v = −∇Φ，p = ρ₀∂Φ/∂t；等熵声速 c₀² = γP₀/ρ₀。
2. 雨课堂已用过的题，网站不要再出同一题或只换数字的同类题。已知例子：牛顿等温声速约 290 m/s 与实测差别的原因；∂p/∂x > 0 处质点加速度方向；推导波动方程必需的三个关系；氦气与空气声速之比。审查时会逐题比对，重复的退回重出。
3. 分工：雨课堂题用于课堂即时检测；网站题用于课前预习和课后自学，可以更深、带计算和解释。
